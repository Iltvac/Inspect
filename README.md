# Автоподбор

Помощник автоподборщика: осмотр машины по чек-листу с фото, замер толщины краски на схеме кузова и отчёт для клиента по ссылке. Работает в браузере на ПК и как приложение на Android. Данные хранятся в Supabase и синхронизируются между устройствами.

## Как пользоваться

1. **Новый осмотр** → вкладка **Машина**: марка, модель, VIN, пробег, цена, для кого подбор.
2. **Краска**: нажми на деталь на схеме и впиши толщину в микронах. Цвет показывает заводскую краску (до 160), перекрас (160–300) и шпатлёвку (300+).
3. **Проверка**: по каждому пункту «В норме / Замечание / Плохо», заметка и фото кнопкой с камерой.
4. **Фото**: общие снимки машины.
5. **Итог**: вывод «Брать / Торговаться / Не брать», комментарий и кнопки отправки ссылки в WhatsApp или Telegram.

Всё сохраняется само. Клиент открывает отчёт без регистрации и может сохранить его в PDF.

## Что внутри

| Путь | Что это |
|---|---|
| `supabase/migrations/001_init.sql` | Таблица осмотров, защита строк (RLS), функция отчёта по ссылке, хранилище фото |
| `src/lib/checklist.ts` | Пункты чек-листа. Новый пункт добавляется одной строкой, база не меняется |
| `src/lib/paint.ts` | Детали кузова и пороги толщины краски |
| `src/lib/useInspection.ts` | Загрузка осмотра и автосохранение |
| `src/lib/photos.ts` | Сжатие фото перед загрузкой и ссылки на них |
| `src/pages/List.tsx` | Список осмотров с поиском |
| `src/pages/Editor.tsx` | Осмотр: вкладки Машина, Краска, Проверка, Фото, Итог |
| `src/pages/Report.tsx` | Отчёт для клиента (открывается без входа) |
| `src/components/PaintDiagram.tsx` | Схема кузова |

## Запуск на компьютере

1. Поставь [Node.js](https://nodejs.org) 20 или новее.
2. `npm install`
3. Скопируй `.env.production` в `.env.local` (там уже адрес базы и публичный ключ).
4. `npm run dev` и открой http://localhost:5173

База Supabase (проект **car-inspect**) уже настроена. Для нового проекта выполни `supabase/migrations/001_init.sql` в SQL Editor.

## Android-приложение

После каждого изменения в `main` GitHub Actions сам собирает APK и выкладывает его в релиз **latest** (вкладка Releases → `inspect.apk`). Установи на телефон, разрешив установку из неизвестных источников.

Ключ подписи APK хранится в секрете репозитория `ANDROID_DEBUG_KEYSTORE` (Settings → Secrets and variables → Actions), в коде его нет. Без этого секрета сборка APK остановится с понятной ошибкой.

## Ссылка на отчёт для клиента

Отчёт открывается на сайте по адресу из `VITE_PUBLIC_URL` (в `.env.production`). Сайт публикуется на GitHub Pages workflow-ом `pages.yml`, но GitHub Pages бесплатно работает только для публичных репозиториев. Пока репозиторий приватный, этот шаг пропускается, и ссылки клиентам не откроются. Варианты:

- сделать репозиторий публичным (секретов в коде нет: ключ публичный, данные закрыты RLS);
- или подключить репозиторий к Netlify / Cloudflare Pages (бесплатно и для приватных) и вписать их адрес в `VITE_PUBLIC_URL`.

Внутри приложения отчёт можно посмотреть кнопкой «Посмотреть отчёт как клиент» в любом случае.

## Идеи на потом

- Свой шаблон чек-листа и логотип подборщика в отчёте.
- Распознавание VIN с фото и подтягивание данных о машине.
- Подписка для подборщиков.
